# Novum

Novum is a small, dynamically evaluated programming language designed to make common research, data-processing, scripting, and general-purpose programming tasks concise without sacrificing access to lower-level functionality.

Its current implementation is written in Rust and uses an interpreter architecture with a lexer, parser, AST, runtime values, environments, modules, and a standard library.

## What Novum is good at

- Compact expression-oriented programs.
- Interactive development through the REPL.
- Numeric work, matrices, vectors, and data-oriented operations.
- Lists, strings, dictionaries, iterators, ranges, pattern matching, and lambdas.
- Small scripts that interact with files, paths, environment variables, and external processes.
- Struct/class-style objects while retaining lambda-based function syntax.
- Module namespaces with visibility and import aliases.

## Current status

Novum is under active development. The documentation in this site describes the language as implemented during the current development line. Some APIs are intentionally documented as implementation-oriented or provisional where their long-term interface has not yet been finalized.
